# Ember House

A responsive restaurant website concept built with React, Vite, Framer Motion, and Lucide React. It is a fictional portfolio demo, not a real restaurant booking service.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite.

## Production build

```powershell
npm.cmd run build
npm.cmd run preview
```

## Included

- Responsive mobile navigation
- Cinematic hero with entrance motion
- Seasonal dish cards with image hover transitions
- Story, dining experience, quote, and visit sections
- Reservation modal with validation and local demo confirmation
- Reduced-motion accessibility support

## Before publishing

The address, hours, phone number, email, prices, and restaurant identity are illustrative placeholders. Replace them with client-approved information. Reservation requests are not sent to a booking system. Photos and web fonts load from external services and require an internet connection.
